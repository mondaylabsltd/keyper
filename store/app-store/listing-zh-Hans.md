## Description (950/4000)

```
在一台离线手机上，Keyper 用你的邮箱和一句只有你知道的话，生成标准 BIP39 助记词。同样的输入总是得到同样的助记词，所以不用抄写，也不怕纸条丢失或被烧毁。Keyper 不保存你输入的任何内容。

使用方法
1. 打开飞行模式，关闭 Wi-Fi 和蓝牙。请保持手机离线后再输入和生成。
2. 用 Keyper 自带的键盘输入邮箱，再输入那句话。
3. 等一分钟左右：Keyper 用 1 GiB 内存跑 128 遍 Argon2id。
4. 把 12 或 24 个词复制到同一台手机上的钱包，或者显示成二维码给另一台设备扫描。

难以暴力破解
Argon2id 提高每次猜测的成本，但攻击者的硬件可能比你的手机快。强度评分只是粗略模型，不能测量你那句话的真实熵，也不是安全保证。名句、歌词、复用密码和公开个人信息，即使评分显示“强”也可能很容易被猜中。

保护措施
- 自带键盘：系统输入法接触不到你输入的内容，无从学习、同步或上传。
- 断网门禁：应用在前台时，检测到连接后，禁止推导，并清除敏感页面内容和 Keyper 的复制内容。iOS 无法确认蓝牙或未连接网络的 Wi-Fi 是否开启，请在系统设置中关闭。
- 不发起网络请求、无需账户、没有统计。
- 在 iOS 支持的范围内遮挡截屏和录屏内容，并在多任务界面隐藏页面；保护效果可能随系统版本变化。
- 复制内容仅限本机，并设置为 60 秒后失效。其他应用的剪贴板历史可能保留副本。
- 恢复演练：使用助记词之前，凭记忆把两样输入再打一遍，核对结果是否一致。

公开，可恢复
推导算法公开并已冻结，Keyper 的每个版本、Android 和 iPhone 上都得到同样的助记词。源代码以 MIT 许可证开源；即使手机丢了，独立的 Python 恢复脚本也能在电脑上算出同一组助记词。

重要
忘了那句话，任何人（包括我们）都没法帮你找回。选一句多年后还记得的话，拼写保持一致，并做一次恢复演练。

Keyper 不是钱包，从不持有或转移资产。生成的助记词可以导入任何支持标准 12 或 24 词 BIP39 助记词的钱包。

需要 iOS 17 及以上，4 GB 以上内存。
官网：https://getkeyper.app/zh
```
